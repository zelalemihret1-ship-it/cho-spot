⚠ Start Workshop ERP From Zero

MAIN ADMIN ONLY

This permanent reset clears Workshop ERP work orders, finished inventory, raw materials and quantities, material movements, sales, stock snapshots, restock history, and activity logs. It also removes financial ledger entries automatically generated from Workshop ERP sales. Admin accounts and assigned permissions are preserved. Customer orders, Mini App products, Telegram settings, and manually entered financial transactions are not changed.

For safety, you must type RESET and confirm a second time. Only the Main Admin can run this action; the server checks access independently.

Workshop Admin Assignment

Main admin only

Choose each category to show that section, then select the exact tasks allowed inside it. Edit and Delete are separate permissions. Raw Materials has separate Add Material, Receive Stock, and Cut / Use Material permissions. You can select multiple categories and tasks for one admin. Admin accounts are managed in the main AMBAR Admin Panel.

Permission rules

Main admin only

A category checkbox controls whether the section is available. Task checkboxes control individual actions. Edit and Delete are separate, and Raw Materials Add Material, Receive Stock, and Cut / Use Material are independent permissions. Server-side checks also enforce assignments.
